# Mobile Sales Dashboard – Power BI

## Project Overview
This project analyzes mobile sales data using Power BI to understand sales performance, revenue, transactions, and customer trends through interactive visualizations.

## Tools Used
- Power BI
- Power Query
- DAX

## Key Features
- Total Sales and Revenue Analysis
- Total Transactions Analysis
- Sales Performance by Mobile Brand and Model
- Customer Ratings Analysis
- Interactive Filters and Slicers
- Monthly and Geographic Sales Analysis

## Objective
The main objective of this project is to analyze mobile sales data, identify sales trends, and provide useful insights to support business decisions.

## Skills Demonstrated
Data Analysis, Data Visualization, Dashboard Design, DAX, and Power Query.

The Power BI dashboard is available in the `.pbix` file uploaded to this repository.
